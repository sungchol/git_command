## visual studio 단축키

- 대문자변환 : ctrl + shift + U
- 소문자변환 : ctrl + U
- 여러단어선택 : shift + alt +.
- 관련단어일괄변경 : ctrl + R + R
- 정의 엿보기 : alt + F12
- 문서정리(json 등) : ctrl + K + D
- 코드감싸기 : ctrl + K + S
- 매개변수보기 : ctrl+ K + P
- 코드검색 빠른전환 : ctrl + T
- 기능옵션선택 : ctrl + Q
- Collapse All : ctrl + M + O
- Collapse Toggle All: ctrl + M + L
- Collapse Toggle Part: ctrl + M + M
- 작업목록 : ctrl +\ + T
- 열린파일목록 : ctrl+ tab , ctrl + shift + tab
